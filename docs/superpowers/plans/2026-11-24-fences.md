# Cercas construídas pelo jogador — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O jogador arrasta cercas (retas ou a 45°) e porteiras que a equipe constrói; a cerca fecha o pasto e os animais só saem pela porteira aberta.

**Architecture:** Cerca por tile (`Tile.fence`), como `Tile.road`: ordem paga na hora e vira uma tarefa `build` por tile (`job.type: 'fence'`). A cerca bloqueia ferramentas, obras e caminho; o pasto de cada animal é a área alcançável a partir da porta do abrigo sem atravessar cerca ou porteira fechada (cache por array de tiles). Cena: `FenceLayer` instanciado, ligando cada tile aos 8 vizinhos.

**Tech Stack:** TypeScript strict, Vitest, React 19 + R3F + drei, Zustand, Tailwind v4.

**Spec:** `docs/superpowers/specs/2026-11-24-fences-design.md`

## Global Constraints

- Lógica pura em `src/game/` (sem React/three); balanceamento só em `src/data/`; cores em `scene/palette.ts`.
- Identificadores em inglês, textos da interface em pt-BR. Sem `any`. `noUncheckedIndexedAccess`.
- Repetidos em `InstancedMesh`; seletores finos no Zustand; `useGameStore.getState()` dentro de `useFrame`; `GameCanvas` não re-renderiza com o HUD.
- Tamanhos visuais em metros via `meters()` (`data/scale.ts`).
- `SAVE_VERSION` 22 → 23 com entrada em `migrations` (v22→v23 só troca o número).
- Só ângulos 0°, 45° e 90°. Materiais são só o detalhamento do preço (sem inventário). Porteira abre/fecha na hora, grátis.
- Cada tarefa termina com `npm run build` e `npm test` verdes, e um commit (mensagem em inglês, terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`), seguido de `git push`.

## Decisões do plano (minhas, ajustes ao spec)

- **Pessoas passam por qualquer porteira** (aberta ou fechada: abrem e fecham atrás de si); só animais respeitam porteira fechada. Senão a equipe ficaria presa fora de um pasto fechado e não coletaria o abrigo.
- **Animais voltando para casa usam `findPath`** (que atravessa porteiras, como pessoas). Assim o animal preso fora de uma porteira fechada consegue voltar; só o passeio (`pickTarget`) respeita a área.
- **`fence-blocks-road` sai do spec:** a cerca só vai em grama sem estrada, então nunca corta a rede de ruas.
- **Cartão de custo** fica no fim da linha arrastada, com `Html` do drei dentro de `BuildGhost`.
- **Demolir uma cerca pronta** devolve `DEMOLISH_REFUND` × custo de um tile reto (ou da porteira); o tile não guarda se era diagonal.

## Review Focus

1. Diagonal sem vão: animal (passeio em linha reta) e pessoa (A*) não atravessam o canto entre dois tiles de cerca ligados na diagonal → teste em Task 3.
2. Porteira fechada com animal fora: ele volta (vaca/boi até o tile mais perto dentro da área; os outros até a porta) e não fica oscilando na porta → testes em Task 4.
3. Carregar save com tarefa de cerca na fila: `repairSiteTasks` não pode apagá-la → teste em Task 2.
4. Arrastar sobre tiles parcialmente ocupados (planta, estrada, construção): ordena só os válidos e cobra só eles → teste em Task 2.
5. Abrigo sem cerca nenhuma: a área é a grama conectada inteira e o comportamento fica igual ao de hoje (limite `LEASH_RADIUS`) → teste em Task 4.

**Interfaces:**
- Consumes: Task 1.
- Produces (em `game/fences.ts`):
  ```ts
  /** 8-connected tiles from a to b, snapped to the nearest 0°/45°/90° direction from a. */
  export const fenceLine = (a: number, b: number): { tiles: number[]; diagonal: boolean };
  export interface MaterialCount { id: FenceMaterialId; label: string; unit: string; amount: number }
  export interface FencePlan {
    tiles: number[];        // the whole snapped line
    valid: number[];        // tiles that will be queued
    blocked: number[];      // tiles skipped
    cost: number;           // coins for the valid tiles (each tile rounded up: Math.ceil of its recipe)
    materials: MaterialCount[]; // summed over the valid tiles, amount > 0 only
    error: ActionError | null;  // 'no-room-for-fence' | 'not-enough-money' | 'queue-full' | null
  }
  export const pieceCost = (piece: FencePiece): number;           // Math.ceil(recipe priced)
  export const fenceError = (state: GameState, tile: number, gate: boolean): ActionError | null; // on projectTasks(state)
  export const fencePlan = (state: GameState, from: number, to: number, gate?: boolean): FencePlan; // gate: line is just `from`
  export const orderFenceLine = (state: GameState, from: number, to: number): ActionResult;
  export const orderGate = (state: GameState, tile: number): ActionResult;
  export const layFence = (state: GameState, tile: number, gate: boolean): ActionResult;  // finished task
  export const removeFence = (state: GameState, tile: number): ActionResult;              // finished removal
  export const toggleGate = (state: GameState, tile: number): ActionResult;               // instant
  export const fenceTaskMinutes = (job: { remove: boolean; gate?: true }): number;
  export const fenceRefund = (tile: Tile): number; // DEMOLISH_REFUND × pieceCost('gate' | 'straight')
  ```
  `DemolishChange` ganha `{ kind: 'fence-cancelled'; refund: number } | { kind: 'fence-removal-queued' }`.

`fenceLine` (o algoritmo que a assinatura não fixa): com `dx, dy` de a para b, escolher a direção entre as 8 cujo ângulo é o mais próximo de `atan2(dy, dx)`; o comprimento é `max(|dx|, |dy|)` se diagonal, senão a projeção no eixo; andar passo a passo nessa direção, parando na borda do mapa.

`fenceError` (no futuro projetado): `out-of-bounds`, `locked`, `structure` (estrutura ou `cover`), `road`, `not-grass` (planta ou terra arada), `already-fence` (para `gate`: tile com cerca que não é porteira é válido; porteira → `already-fence`). Tile com tarefa de cerca na fila conta como cercado (via `projectTasks`).

`orderFenceLine`: plano com `from`/`to`; erro se `valid` vazio (`no-room-for-fence`), `money < cost`, ou fila sem espaço para todas; senão paga `cost` e enfileira um `build` por tile válido com `job: { type: 'fence', remove: false, cost: pieceCost(diagonal ? 'diagonal' : 'straight') }`. Clique simples (`from === to`) num tile cuja última tarefa é cerca a construir cancela essa tarefa e devolve `job.cost` (como `roadClick`). `orderGate`: um tile, `gate: true`, custo `pieceCost('gate')`.

`demolishClick`: antes das estruturas, tarefa de cerca pendente no tile → cancela (reembolso `job.cost` se não é remoção); tile com cerca pronta → enfileira `{ type: 'fence', remove: true, cost: 0 }`. A remoção pronta devolve `fenceRefund`. `cancelAllOrders` devolve `job.cost` de toda tarefa de cerca. `repairSiteTasks` mantém tarefas `build` com job `fence`. Em `workers.ts`, cerca que não pode mais ser aplicada devolve `job.cost`.
